Canonical Conflict

Overview: This issue occurs when a page specifies a canonical URL that points to a different URL, but the target URL itself either points back to the original page (a loop), points to a third page (a chain), or returns a non-200 HTTP status code. This confuses search engines and can result in neither page being indexed or ranked properly.
Recommended Fix: Ensure that the rel="canonical" link element consistently points to the single, definitive version of a page that returns a 200 (OK) status code. Break any canonical chains or loops by pointing all duplicate variants directly to the final destination URL.
